Parsed data

Data readiness

Each segment's archived files are parsed into a checked database right after every fetch. If a check fails, the previous data stays in use. Margins use the start-of-day (i1) SPAN file unless the SuperAdmin switches a segment to the latest cycle.

Only the SuperAdmin can change which SPAN file a segment uses.

Trading days

Holiday calendar

One list per exchange. The fetcher uses it to pick each segment's trading date, and the parsers use it to find the previous trading day and the start-of-day file. Imports read the exchanges' own pages; nothing changes until the SuperAdmin approves.

Only the SuperAdmin can approve imports or change days.
